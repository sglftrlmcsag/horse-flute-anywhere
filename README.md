## Overview

Horse Flute Anywhere is a Stardew Valley mod that removes the location restriction on the horse flute item, allowing farmers to summon their horse from anywhere on the farm, in the mines, or in any outdoor area — not just from the farm entrance. It is compatible with all Stardew Valley expansions including Ginger Island and requires only SMAPI to function.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Horse Flute Anywhere** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Unrestricted Summon** | Summon your horse from the mines, caves, or any outdoor location |
| **SMAPI Compatible** | Works with SMAPI and is compatible with all other SMAPI mods |
| **Ginger Island Support** | Horse can be summoned on Ginger Island and Fern Islands locations |
| **Zero Config** | Works out of the box with no configuration file needed |
